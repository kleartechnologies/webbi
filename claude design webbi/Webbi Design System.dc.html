WebbiDesign system · v1

One system, two surfaces

The product (marketing site, app, editor) has a single fixed identity. Public websites share components, spacing and grammar but swap a personality preset: type pairing, palette, imagery mood and CTA verb. Everything below is expressed as plain CSS values so it can be implemented directly.

11 · Section grammar & responsive

A generated site is structured data (sections with fields), not a page. The AI picks which sections apply; the renderer lays them out with the rules below. No separate desktop template.

Order of sections
  1. Header (logo/name, menu)
  2. Hero (photo, eyebrow, promise, sub)
  3. Primary CTA + quick nav (4)
  4. Featured items (dishes, models, services, listings, portfolio)
  5. Full list / price list / packages
  6. Promotion or trust block (optional)
  7. Gallery (optional)
  8. About (people businesses: advisor, agent, tutor, photographer)
  9. Reviews
  10. Location + hours / service area / delivery info
  11. Footer + sticky CTA bar
Breakpoints
≤ 599Single column. Side padding 20. Hero 4:5. Product grid 2-up (minmax 150). Gallery 3-up. Sticky CTA bar 52px + safe area.
600 – 1023Same markup; auto-fill grids become 3–4 columns, two-column blocks (location + hours, about + reviews) sit side by side. Hero capped at 560.
≥ 10241120 container centred. Hero becomes a 2-column split for people businesses (portrait right). Menu/price lists in 2 columns. Sticky bar stays.
Grid recipescards: repeat(auto-fill, minmax(150px, 1fr))
gallery: repeat(auto-fill, minmax(110px, 1fr))
two-up blocks: repeat(auto-fit, minmax(280px, 1fr))
reviews: repeat(auto-fit, minmax(260px, 1fr))
horizontal rail (models): flex, 78% / max 300px, scroll-snap
